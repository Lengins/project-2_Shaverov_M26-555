# primitive-db

Простая консольная база данных на Python с хранением в JSON-файлах.
Умеет создавать таблицы, вставлять, читать, обновлять и удалять записи.

## Установка

Требуется Python 3.12+ и [uv](https://docs.astral.sh/uv/).

Установить как CLI-инструмент:

```bash
uv tool install primitive-db
```

Или из исходников:

```bash
git clone https://github.com/<ваш-username>/primitive-db.git
cd primitive-db
uv sync
```

## Запуск

```bash
database
```

Откроется интерактивная оболочка:

```
***База данных***

Функции:
<command> create_table <имя_таблицы> <столбец1:тип> .. - создать таблицу
...
>>>Введите команду: _
```

## Управление таблицами

| Команда | Описание |
| :--- | :--- |
| `create_table <имя> <столбец:тип> ...` | Создать таблицу. Столбец `ID:int` добавляется автоматически первым. |
| `list_tables` | Показать список таблиц. |
| `drop_table <имя>` | Удалить таблицу вместе с её данными. |
| `info <имя>` | Показать схему таблицы и количество записей. |

Поддерживаемые типы столбцов: `int`, `str`, `bool`.

**Пример:**

```
>>>Введите команду: create_table users name:str age:int is_active:bool
Таблица "users" успешно создана со столбцами: ID:int, name:str, age:int, is_active:bool

>>>Введите команду: list_tables
- users
```

## CRUD-операции

| Команда | Описание |
| :--- | :--- |
| `insert into <имя> values (<зн1>, <зн2>, ...)` | Добавить запись. ID генерируется автоматически, в списке значений его не указывают. |
| `select from <имя>` | Показать все записи таблицы. |
| `select from <имя> where <столбец> = <значение>` | Показать записи по условию. |
| `update <имя> set <столбец> = <значение> where <столбец> = <значение>` | Обновить записи, подходящие под условие. |
| `delete from <имя> where <столбец> = <значение>` | Удалить записи, подходящие под условие. |

**Правила ввода значений:**

- `int` — без кавычек: `28`, `-5`, `0`.
- `bool` — `true` или `false`, без кавычек, регистр не важен.
- `str` — **в кавычках**: `"Sergei"` или `'Sergei'`.

**Пример полного цикла:**

```
>>>Введите команду: insert into users values ("Sergei", 28, true)
Запись с ID=1 успешно добавлена в таблицу "users".

>>>Введите команду: select from users where age = 28
+----+--------+-----+-----------+
| ID |  name  | age | is_active |
+----+--------+-----+-----------+
| 1  | Sergei |  28 |    True   |
+----+--------+-----+-----------+

>>>Введите команду: update users set age = 29 where name = "Sergei"
Запись с ID=1 в таблице "users" успешно обновлена.

>>>Введите команду: delete from users where ID = 1
Запись с ID=1 успешно удалена из таблицы "users".

>>>Введите команду: info users
Таблица: users
Столбцы: ID:int, name:str, age:int, is_active:bool
Количество записей: 0
```


## Хранение данных

- Схемы таблиц — в `db_meta.json` в корне проекта.
- Данные каждой таблицы — в `data/<имя_таблицы>.json`.
- Обе структуры — обычный JSON, читаются и пишутся функциями из `primitive_db/utils.py`.

## Обработка ошибок и безопасность

- Все ошибки БД централизованно перехватываются декоратором `handle_db_errors`
  и выводятся в формате `Ошибка: …` / `Ошибка валидации: …`.
- Опасные операции (`drop_table`, `delete`) требуют подтверждения:
"Вы уверены, что хотите выполнить "удаление таблицы"? [y/n]: _"
Любой ответ, кроме `y`, отменяет операцию.
- `select` кэширует результаты одинаковых запросов; кэш сбрасывается при
любом `insert`/`update`/`delete`/`drop_table`.
- Время выполнения `insert` и `select` печатается после каждой операции:
`Функция insert выполнилась за 0.001 секунд.`
